# Afaire · plan your day, look after yourself

เว็บแอป (PWA) สำหรับ iPhone รวม to-do list, ปฏิทิน, เช็กอารมณ์, หายใจคลายเครียด, เช็กลิสต์ยา, บันทึกการนอน, บันทึกออกกำลังกาย และ wishlist ไว้ในแอปเดียว
ข้อมูลทั้งหมดเก็บอยู่ในเครื่องของคุณ ส่วนเซิร์ฟเวอร์ (ไม่บังคับ) ใช้แค่ส่งการแจ้งเตือนและให้ AI แยกนัดหมายจากข้อความ

เปิดแอป: https://hyebronde.github.io/Afaire/

---

## 1. เปิดแอปบน iPhone (ฟรี ไม่ต้องตั้งค่าอะไร)

1. ใน GitHub ไปที่ repo นี้ → **Settings** → **Pages**
2. ตรง **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save** จากนั้นรอ 1–2 นาที
3. เปิด https://hyebronde.github.io/Afaire/ ใน **Safari**
4. กดปุ่ม **แชร์** → **เพิ่มไปยังหน้าจอโฮม** แล้วเปิดแอปจากไอคอนบนหน้าจอโฮม

ทำแค่นี้ก็ใช้แอปได้แล้ว ส่วนหน้า New ยังอ่านวันที่และเวลาแบบง่ายๆ ได้เองโดยไม่ต้องใช้ AI

## 2. ตั้งเซิร์ฟเวอร์ เพื่อให้แจ้งเตือนได้และให้ AI อ่านแชทหรือรูปได้ (ฟรี)

ใช้ Cloudflare Workers แบบฟรี โค้ดอยู่ที่ `worker/worker.js`

1. สมัคร https://dash.cloudflare.com
2. **สร้างที่เก็บข้อมูล:** ไปที่ **Storage & Databases** → **KV** → **Create** ตั้งชื่อ `afaire`
3. **สร้าง Worker:** ไปที่ **Workers & Pages** → **Create** → **Create Worker** ตั้งชื่อ `afaire` → **Deploy** → **Edit code** แล้ววางโค้ดทั้งหมดจาก `worker/worker.js` → **Deploy**
4. ใน Worker ไปที่ **Settings** แล้วตั้งค่า 3 อย่างนี้:
   - **Bindings** → **Add** → **KV namespace** ตั้งชื่อตัวแปรว่า `AFAIRE` แล้วเลือก `afaire`
   - **Variables and Secrets** → เพิ่ม Secret ชื่อ `GEMINI_API_KEY` ใส่ key ที่ได้จากขั้นตอนที่ 5
   - (แนะนำ) เพิ่ม Secret ชื่อ `APP_TOKEN` ตั้งเป็นรหัสผ่านอะไรก็ได้ เพื่อกันคนอื่นมาใช้เซิร์ฟเวอร์ของคุณ
5. **ขอ Gemini key:** ไปที่ https://aistudio.google.com/apikey → **Create API key** แล้วคัดลอกมาใส่ในขั้นตอนที่ 4
6. **ตั้งให้ส่งแจ้งเตือนทุกนาที:** ใน Worker ไปที่ **Settings** → **Trigger Events** → **Add** → **Cron Triggers** ใส่ `* * * * *`
7. **เชื่อมกับแอป:** เปิดแอป → **Me** → **Settings**
   - ใส่ที่อยู่ Worker เช่น `https://afaire.ชื่อคุณ.workers.dev` และรหัส APP_TOKEN (ถ้าตั้งไว้)
   - กด **Check** แล้วกด **Turn on reminders**

ถ้าวันหลังอยากเปลี่ยนรุ่น AI ให้เพิ่ม Variable ชื่อ `GEMINI_MODEL` ใน Worker (ค่าเริ่มต้นคือ `gemini-flash-lite-latest`)

## แอปจะแจ้งเตือนอะไรบ้าง

- **นัดหมาย:** ล่วงหน้าตามที่ตั้งไว้ (ค่าเริ่มต้น 30 นาที)
- **งานที่ใส่เวลาไว้:** แจ้งตอนถึงเวลา
- **ยา:** ทุกวันตามเวลาของแต่ละมื้อ ถ้าติ๊กว่ากินแล้วจะไม่แจ้งซ้ำ
- **หายใจ:** 3 รอบต่อวัน คือ เช้า กลางวัน เย็น เปลี่ยนเวลาได้ใน Settings

แอปจะส่งรายการแจ้งเตือนล่วงหน้า 8 วันไปไว้ที่เซิร์ฟเวอร์ทุกครั้งที่เปิดแอป ควรเปิดแอปอย่างน้อยสัปดาห์ละครั้งเพื่อให้แจ้งเตือนไม่ขาด

## ข้อมูลที่ใช้ออกแบบ

- **การหายใจ:** Cyclic sigh ตั้งเป็นค่าเริ่มต้น ตามงานวิจัยของ Stanford (Balban et al., *Cell Reports Medicine*, 2023) ที่ให้ทำวันละ 5 นาที
- **การนอน:** เกณฑ์ 7 ชั่วโมงขึ้นไป และเรื่องเวลาเข้านอนที่สม่ำเสมอ อ้างอิงจาก American Academy of Sleep Medicine
- **ออกกำลังกาย:** เป้าหมาย 150 นาทีต่อสัปดาห์ และฝึกกล้ามเนื้อ 2 วันต่อสัปดาห์ อ้างอิงจาก WHO

แอปนี้ไม่ใช่คำแนะนำทางการแพทย์

## ไฟล์

- `index.html` หน้าตาและสไตล์ทั้งหมด
- `core.js` ข้อมูล วันที่ การแจ้งเตือน และตัวแยกข้อความ
- `views.js` หน้าจอทั้ง 13 หน้า
- `main.js` การกด ฟอร์ม และหน้าต่างแก้ไข
- `sw.js` ใช้งานออฟไลน์และรับการแจ้งเตือน
- `worker/worker.js` เซิร์ฟเวอร์บน Cloudflare (AI + แจ้งเตือน)
